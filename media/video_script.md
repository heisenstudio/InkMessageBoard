# Demo Video Script

## Title

ESP32 墨水屏 MQTT 留言板原型

## 30-60 Second Flow

1. Show the assembled device.
2. Show the Android app input screen.
3. Enter a short message.
4. Tap send.
5. Show MQTT message being delivered, if you want to include a debug shot.
6. Show the e-paper display refreshing.
7. End with the GitHub repository structure: firmware, android, hardware, docs.

## Key Message

这是一个 ESP32 + 墨水屏 + MQTT + Android App 的留言板原型项目。核心功能已跑通，适合作为嵌入式 IoT 学习和作品集参考。
