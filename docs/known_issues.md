# Known Issues

这个项目目前就是学习原型，下面这些问题都可以继续改。

## 固件

- Wi-Fi/MQTT 重连逻辑还比较朴素。
- MQTT TLS 当前使用 `setInsecure()`，没有严格校验证书。
- 墨水屏刷新慢是正常现象，频繁全刷会闪烁。
- 中文字体和排版还可以继续整理。
- 固件里的部分 UI 文案/编码建议后续再统一检查。
- 电池百分比目前是按电压简单估算，不是精确电量计。

## Android

- MQTT 配置页比较基础。
- 连接失败时的错误提示还不够细。
- 默认包名还是示例风格，后续可以整理成更合适的命名。
- 目前没有做账号安全、证书管理、消息历史持久化等产品化能力。

## 硬件

- 三块板子的资料已经整理进仓库，但发布/打板前仍建议重新核对版本。
- BOM 和贴片坐标来自工程输出，最好再人工检查一遍。
- 装配说明还需要继续补照片，特别是排线方向和电源连接。
- 没有做完整的生产测试流程。

## 文档

- 构建步骤还需要从干净电脑完整跑一遍。
- 系统架构图和 MQTT 流程图还没有正式绘制。
- 视频演示素材可以继续补。
